# brushio.github.io

Website for [Brushio](https://apps.apple.com/app/brushio/id6771890992), an iOS and watchOS app for better toothbrushing and dental care.

**Live site:** https://brushio.github.io/

- Home page in English and Ukrainian
- [Privacy Policy](https://brushio.github.io/privacy/), [Terms of Use](https://brushio.github.io/terms/), [Support](https://brushio.github.io/support/)

Built with Jekyll and published to GitHub Pages by GitHub Actions on every push to `main`. The site loads no third-party scripts, fonts or analytics.
